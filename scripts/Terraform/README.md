# Terraform download catalog

Organized AWS CPU/GPU, Azure CPU and linked Ollama Terraform project, plus retained standalone CPU downloads.

[Deployment guide](https://guides.fortinetpslab.com/cpu.html) · [Public downloads](https://github.com/WEEMR/FortiAIGate)

Approved version: **2026-11-02.8**, selected by [current.json](current.json).

Use the approved [ZIP](FortiAIGate_MultiCloud_Terraform.zip) or the complete [FortiAIGate_Terraform/ project](FortiAIGate_Terraform/), starting at its root with its own state. Its AWS, Azure and Shared_Resources folders belong together. The flat main.tf and .terraform.lock.hcl downloads retain the earlier standalone CPU configuration for saved callers; they do not migrate existing state to this project. Follow the published [runtime instructions](FortiAIGate_Terraform/Shared_Resources/README.md).

Current entry points and direct downloads:

- [main.tf](https://raw.githubusercontent.com/WEEMR/FortiAIGate/approved/scripts/Terraform/main.tf) — Retained standalone CPU configuration for selecting one AWS or Azure lab with its own state; this flat compatibility route is separate from the organized project.
- [.terraform.lock.hcl](https://raw.githubusercontent.com/WEEMR/FortiAIGate/approved/scripts/Terraform/.terraform.lock.hcl) — Exact AWS/Azure provider selections and accepted provider package checksums for the retained standalone CPU main.tf; not the organized project lockfile.
- [FortiAIGate_MultiCloud_Terraform.zip](https://raw.githubusercontent.com/WEEMR/FortiAIGate/approved/scripts/Terraform/FortiAIGate_MultiCloud_Terraform.zip) — Organized-project Terraform archive containing the complete FortiAIGate_Terraform/ project, sanitized disabled inputs and runtime instructions; the flat standalone main.tf/lockfile are separate compatibility downloads.
- [README.txt](https://raw.githubusercontent.com/WEEMR/FortiAIGate/approved/scripts/Terraform/README.txt) — Release usage guide for the organized multi-cloud ZIP, safe inputs, installation and lifecycle; also explains the retained standalone CPU compatibility routes.
- [SHA256SUMS](https://raw.githubusercontent.com/WEEMR/FortiAIGate/approved/scripts/Terraform/SHA256SUMS) — SHA-256 checksums for this release's Terraform files, usage instructions and downloadable ZIP.

Versioned downloads use [immutable terraform-2026-11-02.8](https://github.com/WEEMR/FortiAIGate/releases/tag/terraform-2026-11-02.8). Older versions remain listed for reproducibility and rollback. This generated README indexes the existing files; it is separate from their frozen manifests and checksums.
